## Style conventions

- Lowercase prose throughout (no title case in content lines)
- Em dashes (`—`) used as separators between project name and description
- Horizontal rules (`---`) separate sections
- No headers (`#`) — sections are implied by `**bold**` labels
- Minimal punctuation; concise phrasing
